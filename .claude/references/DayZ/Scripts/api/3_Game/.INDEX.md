`3_Game` (`gameScriptModule`) — игровой слой DayZ. Содержит основной класс игры (CGame/DayZGame), систему сущностей (Entity→EntityAI→Man/Building/Object), управление игроком (HumanInputController, камеры, предметы в руках), инвентарь (GameInventory, HandFSM), систему урона и кровотечений, погоду, звук, эффекты и пост-обработку (PPEManager), транспорт (Car/Helicopter/Boat), сеть (RPC, Hive, REST), UI, ИИ, центральную экономику и конфигурацию геймплея. Надстройка над 2_GameLib, база для 4_World.

Также содержит: BIOS-сервисы, аналитику, автотесты, Xbox demo — не документированы, не используются в PC-моддинге.
