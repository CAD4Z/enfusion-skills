`2_GameLib` (`gameLibScriptModule`) — игровой библиотечный слой. Содержит класс Game (lifecycle, спавн), систему callback'ов (ScriptCallQueue, ScriptInvoker, ScriptCaller), ввод (InputManager), меню (MenuManager), настройки (Settings), компонентную систему (GenericComponent, ScriptComponent), расширенные сущности (GenericEntity, CharacterEntity) и тестовый фреймворк. Надстройка над 1_Core, база для 3_Game.
