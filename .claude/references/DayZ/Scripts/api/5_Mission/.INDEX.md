`5_Mission` (`missionScriptModule`) — верхний слой клиента и сервера. Содержит классы миссий (lifecycle game/server/main menu), HUD поверх игрового мира (stats, quickbar, vehicle HUD, gameplay effects), инвентарный UI (drag & drop, vicinity, контейнеры), все in-game меню (inspect, map, note, gestures, respawn, …), главное меню с character creation и server browser, чат, dev-инструменты (ScriptConsole, SceneEditor, CameraTools). Надстройка над 4_World, точка входа всей UI-части игры.
