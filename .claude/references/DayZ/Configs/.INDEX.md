`config.cpp` — конфигурационный файл в корне каждого PBO/мода, который описывает его содержимое, определяет игровые сущности и их свойства через иерархию классов. Синтаксис C++-подобный.
Может быть опционально бинаризирован при сборке PBO. 

Все конфиги всех загруженных PBO мержатся движком в единое дерево — классы с одинаковыми именами в одном Cfg-разделе дополняют/перезаписывают друг друга.

### Навигация

`@.claude/references/DayZ/Configs/Classes/cfg_patches.md` - регистрирует PBO в системе аддонов движка(обязательный)  
`@.claude/references/DayZ/Configs/Classes/cfg_mods.md` - описывает мод и указывает, какие скриптовые модули подключать(обязательный)  
`@.claude/references/DayZ/Configs/Classes/cfg_vehicles.md` - основной реестр сущностей  
`@.claude/references/DayZ/Configs/Classes/cfg_weapons.md` - реестр оружия  
`@.claude/references/DayZ/Configs/Classes/cfg_magazines.md` - реестр магазинов и россыпных патронов  
`@.claude/references/DayZ/Configs/Classes/cfg_ammo.md` - реестр снарядов/пуль  
`@.claude/references/DayZ/Configs/Classes/other_cfg.md` - остальные классы конфигов

`@.claude/references/DayZ/Configs/mod_cpp.md` - отвечает за отображение в главном меню  
`@.claude/references/DayZ/Configs/scripts_api.md` - чтение конфигов из Enforce Script
