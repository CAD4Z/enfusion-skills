## EDDS — формат текстур Enfusion

`.edds` (Enfusion DDS) — формат текстур движка Enfusion. Создаётся из исходных изображений (PNG, TGA) через импорт в Workbench. Настройки импорта хранятся в `.edds.meta` файлах рядом с текстурой.

Для UI `.edds` текстуры используются как источник для imageset-атласов — см. `@.claude/references/DayZ/Imagesets/imagesets.md`.

Каждый ресурс получает GUID при импорте: `{D2377E3C2ECB1102}sample_glass_smdi.png`

### Платформы

Настройки импорта задаются **отдельно для каждой платформы**: PC, XBOX_ONE, PS4, LINUX.

### Свойства импорта

#### TargetFormat

Формат выходного файла.

| Значение | Описание |
|----------|----------|
| `EnfusionDDS` | Стандартный формат Enfusion |
| `DirectXDDS` | Совместимый с DirectX DDS |
| `EnfusionDDS_LZ0` | Enfusion DDS со сжатием LZ0 |
| `EnfusionDDS_LZ4` | Enfusion DDS со сжатием LZ4 |

#### FormatCompress

Скорость/качество сжатия формата.

| Значение | Описание |
|----------|----------|
| `Copy` | Без сжатия — копирование как есть |
| `Fastest` | Быстрое сжатие (по умолчанию) |
| `Medium` | Среднее качество |
| `Best` | Максимальное качество, медленное |

#### CompressTreshold

Порог сжатия. Значение: `0–100`, по умолчанию `80`. Определяет агрессивность сжатия.

#### RemoveMips

Количество mip-уровней для удаления. Значение: `0+`, по умолчанию `0`.

#### Conversion

Формат конвертации каналов текстуры.

| Значение | Описание |
|----------|----------|
| `None` | Без конвертации |
| `DXTCompression` | Стандартное DXT сжатие |
| `Alpha` | Только альфа-канал |
| `Red` | Только красный канал |
| `RedHQCompression` | Красный канал, высокое качество |
| `RedGreen` | Красный + зелёный каналы |
| `RedGreenHQCompression` | RG каналы, высокое качество |
| `ColorHQCompression` | Цвет, высокое качество |
| `HDRCompression` | HDR-сжатие |

#### ConversionQuality

Качество конвертации. Значение: `0.0–1.0`, по умолчанию `0.050`.

#### Swizzling

Перестановка/преобразование каналов текстуры.

| Значение | Назначение |
|----------|-----------|
| `None` | Без преобразования |
| `TerrainLayerTexture` | Слой текстуры ландшафта |
| `TerrainSuperTexture` | Супертекстура ландшафта |
| `TerrainNormalSpecular_SYxX` | Нормаль+спекуляр ландшафта |
| `AlphaToRGB` | Альфа-канал в RGB |
| `SMDIToGS` | SMDI-карта в GS-формат |
| `NormalMap_NOHQ` | Карта нормалей без HQ |
| `NormalMapGA` | Карта нормалей (GA-формат) |
| `NormalSpecularMapXYZS` | Нормаль+спекуляр (XYZS) |
| `AmbientSpecularMapGA` | Эмбиент+спекуляр (GA) |
| `ColorNoise` | Цветовой шум |

#### MipMap-настройки

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `ContainsMips` | bool | `false` | Исходный файл уже содержит mip-уровни |
| `GenerateMips` | bool | `true` | Генерировать mip-уровни при импорте |
| `Normalize` | bool | `false` | Нормализовать при генерации мипов |

#### MipMapFunction

Функция генерации mip-уровней.

| Значение | Описание |
|----------|----------|
| `Filter` | Фильтрация (стандарт) |
| `Normalize` | Нормализация (для карт нормалей) |
| `ColorNoise` | С добавлением шума |

#### MipMapFilter

Фильтр уменьшения при генерации мипов.

| Значение | Описание |
|----------|----------|
| `Box` | Box-фильтр (стандарт) |
| `Triangle` | Треугольный фильтр |
| `Kaiser` | Фильтр Кайзера (высокое качество) |

#### Прочие

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `TiledTexture` | bool | `true` | Текстура тайлится (повторяется) |
| `GenerateCubemap` | bool | `false` | Генерировать кубическую карту |

### General

| Свойство | Тип | Описание |
|----------|-----|----------|
| `SourceFile` | string | Путь к исходному файлу (PNG, TGA) |
