### Объявление функций

Функция состоит из типа возвращаемого значения, имени и списка параметров. Могут объявляться глобально или внутри класса.

```cpp
void MethodA() {}                     // без параметров и возвращаемого значения
int GiveMeTen() { return 10; }       // возвращает int
float Sum(float a, float b)          // два параметра
{
    return a + b;
}
```

### Параметры

- Типизированные и фиксированные (нет variadic-параметров)
- Поддержка значений по умолчанию

```cpp
void PrintNum(int a = 0) // параметр по умолчанию
{
    Print(a);
}
PrintNum();  // выведет 0
PrintNum(7); // выведет 7
```

**out** — параметр передаётся по ссылке (значение возвращается из функции через параметр):
```cpp
void GetValues(out int val1, out int val2, int val3)
{
    val1 = 11; // изменит переменную вызывающего кода
    val2 = 12; // изменит переменную вызывающего кода
    val3 = 13; // НЕ изменит — передан по значению
}
```

**inout** — параметр передаётся по ссылке, используется и изменяется функцией.

### Перегрузка функций

```cpp
float Sum(float a, float b) { return a + b; }
float Sum(int a, int b)     { return a + b; } // перегруженная версия
```

### Модификаторы функций/методов

| Модификатор | Описание |
|-------------|----------|
| `private` | Вызов только из методов того же класса |
| `protected` | Вызов из методов класса и его наследников |
| `static` | Вызов без объекта: `ClassName.Method()`. Доступ только к `static`-членам |
| `override` | Компилятор проверяет наличие метода в базовом классе и совпадение сигнатуры |
| `proto` | Прототип внутренней функции (C++ сторона) |
| `native` | Native call convention внутренней функции (C++ сторона) |

### Перегрузка оператора индекса

Через методы `Set` и `Get`. Допускается любое количество перегрузок без конфликта типов:

```cpp
class IndexOperatorTest
{
    int data[3];

    void Set(int _index, int _value)
    {
        data[_index] = _value;
    }

    int Get(int _index)
    {
        return data[_index];
    }
}

auto instance = new IndexOperatorTest();
instance[1] = 5;       // вызывает Set(1, 5)
Print(instance[1]);     // вызывает Get(1), выведет 5
```

Для присвоения вектора через строку (`instance[i] = "1 1 1"`) setter должен принимать `string` и конвертировать через `.ToVector()`.
