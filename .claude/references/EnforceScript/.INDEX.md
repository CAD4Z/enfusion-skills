Enforce Script — C++ подобный скриптовый язык движка Enfusion Engine, используемый для определения всей внутриигровой логики DayZ. Поддерживает ООП с одиночным наследованием, шаблоны, подсчёт ссылок (ARC) и систему `modded`-классов для моддинга без изменения оригинальных скриптов.

### Критические ограничения
1. Никогда не использовать тернарные операторы и/или перенос строки с кодом.
