Enforce Script — C++ подобный язык для движка Enfusion Engine. Весь код должен находиться внутри функций или классов.

### Структура программы

```cpp
class MyClass
{
    void Hello()
    {
        Print("Hello World"); // ok
    }
}

void Hello()
{
    Print("Hello World"); // ok — глобальная функция
}

Print("Hello World"); // ошибка — код вне функции не выполняется
```

### Блоки кода и области видимости

Фигурные скобки `{}` определяют область видимости. Переменные доступны только внутри своего блока. Повторное объявление переменной с тем же именем во вложенном или соседнем блоке (включая `else`) вызывает ошибку множественного объявления.

### Примитивные типы

| Тип | Диапазон | Значение по умолчанию |
|-----|----------|----------------------|
| `int` | -2,147,483,648 .. +2,147,483,647 | `0` |
| `float` | ±1.401298E-45 .. ±3.402823E+38 | `0.0` |
| `bool` | `true` / `false` | `false` |
| `string` | — | `""` |
| `vector` | 3 float-компонента | `"0 0 0"` |
| `void` | — | — |
| `Class` | — | `null` |
| `typename` | runtime-тип | `null` |

### Переменные и константы

```cpp
int a;          // объявление
a = 5;          // присваивание
int b = 9;      // инициализация
const int MONTHS_COUNT = 12; // константа — только для чтения
```

### Автоопределение типа

Ключевое слово `auto` определяет тип переменной по значению на этапе компиляции:

```cpp
auto x = 1;                    // int
auto y = 1.0;                  // float
auto obj = new MyClass();      // MyClass
```

### Строки

- Передаются **по значению** (как примитивы)
- Конкатенация оператором `+`
- Escape-последовательности: `\n` `\r` `\t` `\\` `\"`

### Векторы

- Передаются **по значению**
- Инициализация строкой: `vector up = "0 1 0";`
- Доступ к компонентам через `[]`: `up[1] = -1;`

### Комментарии

```cpp
// однострочный комментарий
/* многострочный
   комментарий */
```

### Операторы

Приоритет аналогичен C/C++.

**Арифметические**: `+` `-` `*` `/` `%`

**Присваивания**: `=` `+=` `-=` `*=` `/=` `|=` `&=` `<<=` `>>=` `++` `--`

**Сравнения**: `>` `<` `>=` `<=` `==` `!=`

**Прочие**:

| Категория | Операторы |
|-----------|-----------|
| Логические | `&&`, `||` |
| Побитовые | `&`, `|`, `~`, `^` |
| Сдвиг | `<<`, `>>` |
| Строковые | `+` |
| Индексация | `[]` |
| Отрицание | `!` |

### Управляющие конструкции

Работают аналогично C/C++.

**if / else if / else**:
```cpp
if (a > 10)
{
    // ...
}
else if (a > 5)
{
    // ...
}
else
{
    // ...
}
```

**switch** — поддерживает числа, константы и строки:
```cpp
switch (name)
{
    case "john":
        Print("Hello John!");
        break;
    default:
        Print("Unknown");
        break;
}
```

**for**:
```cpp
for (int i = 0; i < 3; i++)
{
    Print(i);
}
```

**foreach** — итерация по массивам и map:
```cpp
// по значению
foreach (int v : myArray)
{
    Print(v);
}

// с ключом (индекс для массива, ключ для map)
foreach (int i, string val : myArray)
{
    Print("arr[" + i + "] = " + val);
}

// map — ключ и значение
foreach (auto key, auto val : myMap)
{
    Print(key + " = " + val);
}
```

**while**:
```cpp
while (i < 3)
{
    Print(i);
    i++;
}
```

### Массивы

**Статические** — фиксированный размер на этапе компиляции:
```cpp
int arr[3];                          // объявление
int arr2[3] = {53, 90, 7};          // инициализация
const int SIZE = 5;
int arr3[SIZE];                      // размер через константу
int size = 3;
int arr4[size];                      // ошибка — переменная не допускается
```

**Динамические** — через шаблонный класс `array<T>`:
```cpp
autoptr TStringArray names = new TStringArray; // TStringArray = array<string>
names.Insert("Peter");
string name = names.Get(1);      // или names[1]
names.Remove(1);
int count = names.Count();
```

Предопределённые typedef:

| Typedef | Раскрытие |
|---------|-----------|
| `TStringArray` | `array<string>` |
| `TFloatArray` | `array<float>` |
| `TIntArray` | `array<int>` |
| `TClassArray` | `array<class>` |
| `TVectorArray` | `array<vector>` |

Динамические массивы — это объекты: используйте `autoptr` или `delete` для освобождения памяти.
