### Основы ООП в Enforce Script

- Все члены класса (функции и переменные) **публичные по умолчанию**
- Методы классов виртуальные — могут быть переопределены наследником
- Используйте `override` при переопределении (защита от случайного переопределения)
- Наследование от одного родителя через `:` или `extends`
- Переменные класса инициализируются значениями по умолчанию при создании
- Объекты не создаются/уничтожаются автоматически — используйте `new`/`delete` или `autoptr`

### Объекты

Объекты — это ссылки, передаются **по ссылке**:

```cpp
class MyClass
{
    void Say() { Print("Hello world"); }
}

void Example()
{
    MyClass o;                // o == null
    o = new MyClass;          // создание экземпляра
    o.Say();                  // вызов метода
    delete o;                 // уничтожение

    autoptr MyClass a = new MyClass; // автоматическое удаление при выходе из области видимости
    a.Say();
    // delete вызывается автоматически в конце scope
}
```

Всегда проверяйте объект на `null` перед обращением:
```cpp
void SafeMethod(MyClass o)
{
    if (o)
        o.Say();
}
```

### Наследование

```cpp
class AnimalClass
{
    void MakeSound() {}
}

class Dog: AnimalClass          // или: class Dog extends AnimalClass
{
    override void MakeSound()
    {
        Print("Wof!");
    }
}
```

Полиморфизм работает — можно передать `Dog` как `AnimalClass`.

### this и super

```cpp
class HoneyBadger: AnimalClass
{
    override void Hello()
    {
        Print("HoneyBadger");
    }

    void Test()
    {
        Hello();        // HoneyBadger
        this.Hello();   // HoneyBadger — ссылка на текущий объект
        super.Hello();  // AnimalClass — вызов метода базового класса
    }
}
```

### Конструктор и деструктор

- Конструктор — функция с именем класса, вызывается при `new`
- Деструктор — `~ИмяКласса()`, вызывается при `delete`/`autoptr`
- Каждый класс может иметь один конструктор и один деструктор
- Конструктор может принимать параметры, деструктор — нет
- Оба возвращают `void`
- Вызываются в том числе при создании/удалении из C++
- Если конструктор без параметров — скобки при `new` опускаются

```cpp
class MyClassA
{
    void MyClassA() { Print("Created!"); }      // конструктор
    void ~MyClassA() { Print("Destroyed!"); }   // деструктор
}

class MyClassB
{
    string m_name;
    void MyClassB(string name)                   // конструктор с параметром
    {
        m_name = name;
    }
    void ~MyClassB() {}
}

void Method()
{
    MyClassA a = new MyClassA;               // без скобок — конструктор без параметров
    MyClassB b = new MyClassB("Michal");     // со скобками — есть параметры
    delete b;
} // a уничтожается автоматически через ARC
```

### Модификаторы доступа

| Модификатор | Переменные | Методы |
|-------------|-----------|--------|
| `private` | Доступ только из методов класса | Вызов только из методов класса |
| `protected` | Доступ из класса и наследников | Вызов из класса и наследников |
| (по умолчанию) | Публичный доступ | Публичный доступ |

### Модификаторы переменных

| Модификатор | Описание |
|-------------|----------|
| `static` | Доступ без объекта: `ClassName.variable` |
| `const` | Константа, нельзя изменять |
| `autoptr` | Объект автоматически удаляется при выходе переменной из scope |
| `ref` | Переменная — сильная ссылка (см. `@special.md`) |
| `proto` | Прототип внутренней переменной (C++) |
